# Supported Markdown

This is a basic Markdown template that demonstrates common Markdown formatting.

## Headers

You can create headers with the `#` symbol. The number of `#` symbols indicates the header level. For example:

### Subheading

## Text Styling

You can apply text styling to your content, such as making text **bold** or _italic_:

- **Bold text**
- _Italic text_

## Lists

Markdown supports ordered and unordered lists:

1. Ordered list item
2. Another ordered list item

- Unordered list item
- Another unordered list item

## Links

You can create links to websites or other resources:

[OpenAI](https://www.openai.com)

## Images

You can embed images in your document:

![Alt text](https://via.placeholder.com/150)

## Horizontal Rules

You can create horizontal rules with three or more dashes, asterisks, or underscores:

---

## Tables

Markdown supports simple tables:

| Header 1 | Header 2 |
| -------- | -------- |
| Cell 1   | Cell 2   |

## Inline HTML

You can use inline HTML if needed:

<em>This is emphasized text using HTML.</em>

## Escape Characters

You can escape Markdown special characters using a backslash `\` to display them as literal characters.

\*This is not italic\*



## Checkboxes

- [x] Task 1
- [ ] Task 2


# Unsupported Markdown

## Blockquotes - NOT SUPPORTED

You can create blockquotes:

> This is a blockquote.

## Code - NOT SUPPORTED

You can format inline code with backticks \`code\`, or create code blocks:


## Footnotes - NOT SUPPORTED

This is a footnote[^1].

[^1]: Footnote content goes here.

## Citations - NOT SUPPORTED

You can add citations:

> This is a quote[^2].

[^2]: Source of the quote.

Feel free to use this template as a starting point and expand it with additional Markdown features as needed for your specific document.

## Miscellaneous - NOT SUPPORTED

Markdown supports other features like strikethrough, superscript, and more, depending on the specific Markdown flavor you're using.

~~Strikethrough~~
x^2^
